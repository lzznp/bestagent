
【可选条件清单（**照抄这里的合法值，别自己编**；来源 = 配方表 page_recipes.json 实测）】
- `keyword`｜包含全部关键词｜自由文本
- `job_title`｜职位名称｜自由文本 / 全部
- `company`｜公司名称｜自由文本
- `city_current`｜目前城市｜快捷列表动态（页面记忆最近选择，实测出现过 青岛/成都/杭州/西安/北京/上海/深圳/秦皇岛）+ 面板全量
- `city_expected`｜期望城市｜快捷列表（许昌/武汉/广州/北京/无锡/大连/郑州/杭州 等动态）+ 面板全量
- `years`｜工作年限｜只能填：不限 / 应届生 / 1-3年 / 3-5年 / 5-10年 / 10年以上 / 自定义
- `education`｜教育经历｜只能填：不限 / 本科 / 硕士 / 博士/博士后 / 大专 / 中专/中技 / 高中及以下
- `tongzhao`｜统招要求｜只能填：统招/非统招（不限） / 统招本科 / 统招硕士 / 统招博士 / 统招大专
- `school`｜院校要求｜只能填：不限 / 211 / 985 / 双一流 / 海外留学
- `age`｜年龄｜自由数字
- `activity`｜活跃度｜只能填：不限 / 今天活跃 / 3天内活跃 / 7天内活跃 / 30天内活跃 / 最近三个月活跃 / 最近半年活跃 / 最近一年活跃
- `gender`｜性别｜只能填：不限 / 男 / 女
- `jobhop`｜跳槽频率｜待补（下拉可开，选项文字未捕获）
- `language`｜语言｜只能填：不限 / 普通话 / 英语 / 日语 / 法语 / 粤语 / 其他
- `salary_expected`｜期望年薪｜自由数字
- `salary_current`｜目前年薪｜自由数字
- ⚠️ **配方表里还没实测通的组**（别写进计划）：当前行业、当前职位
⚠️ 三条已知坑：① `keyword` 里**空格分隔 = 全部命中（AND）**，词内别叠同义词/多词，否则极易 0 命中（同义叫法要么拆成多条关键字、要么改用「包含任意」——⚠️ 目前**代码只支持「全部」**）；② `years` **没有"5-8年"这种档**——JD 的年限若落在档与档之间，取**最接近**的档，别自己造值；③ `activity` 是**「今天活跃」不是「今日活跃」**，应届岗慎用（应届普遍不活跃，会筛空）。
⚠️ 条件里**只放硬门槛**（JD 写了「必须有」的）；「有更好」的优先条件**一律不写**，否则误杀。
