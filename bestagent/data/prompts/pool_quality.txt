【候选人列表（已采集候选人的原始文本，每段用 --- 分隔）】
{candidates_text}

    "pool_quality": "优/良/中/差",
    "match_distribution": {"high": 0, "medium": 0, "low": 0, "total": 0},
    "main_gaps": ["候选人池的主要缺口，如技能、经验、学历等"],

}

说明：
- match_distribution.high/medium/low 按匹配得分分档统计（≥80 / 60-79 / <60），无得分数据填 0
- pool_quality 综合判断候选人池的数量与质量
- recommendation 用 2-3 句话给出可执行建议
- data_valid 默认为 true，只有当候选人信息与岗位描述完全无关时才设为 false
- data_valid_message 在 data_valid 为 false 时给出具体提醒
