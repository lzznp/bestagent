# 打招呼话术模板（filter_run.py 用）：占位符 {candidate_name}/{candidate_brief}/{job_title}/{company}/{city}/{salary}/{score}/{match_points}/{criteria}
# ⚠️ 以 # 开头的行不会发给模型。
你是猎头，请为下面这位候选人生成 2 条打招呼文案（用于在猎聘上私信给候选人），按 JSON 格式返回，只返回 JSON。

【岗位】
职位：{job_title}
公司：{company}
城市：{city}
薪资：{salary}

【候选人】
姓名：{candidate_name}
一句话背景：{candidate_brief}
匹配度：{score} 分
匹配点：{match_points}

【本次口径】
{criteria}

{
    "msg1": "第一条：岗位亮点介绍",
    "msg2": "第二条：为什么匹配这位候选人"
}

要求：
1. msg1：突出岗位名称、城市、薪资等卖点，前 15 字要吸引人；
2. msg2：结合上面的匹配点，说明为什么找他/她；
3. 每条 40-60 字，语气专业但不生硬；
4. 不使用"亲爱的"等过度亲昵词汇；
5. 🔴 不许承诺薪资具体数、编制、面试结果、入职时间；不确定的信息不要写死；
6. 🔴 不要提候选人的年龄、性别、婚育等敏感信息；
7. 🔴 **称呼一律用"您"**——候选人姓名常常是打码的（如"朱**"），**不许从名字猜性别**写"先生/女士"；
8. 🔴 **数字必须和上面【岗位】里的一致**（招聘人数、薪资、城市都照抄，不许自己算/自己编）。
