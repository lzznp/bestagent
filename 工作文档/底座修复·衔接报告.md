### 2.6 停止开关（A+B）

- **根因**：popup 的暂停/急停只看 `/api/agent/runs` 里 `status=='running'` 的 **agent run**，而 agent run 只由**桥自带 LLM 循环**（控制台「▶ 运行 Agent」）创建；**小猎走 `/api/task` 单动作队列（`submit_task`），不创建 run** → 按钮**永远灰**。
  → ⚠️ **同时修正了口头讨论里的一个错误说法**："暂停/急停是人在回路的安全阀" —— 对 2026-08 的 P0/P2 形态成立，**对现在的链路无效**（此前其实**没有**安全阀）。
- **A 总闸**：`POST /api/control/stop`（记 `stopped_at` + 清空待执行队列；被清任务标 `failed + 人工停止（清空待执行队列）`）+ `GET /api/control/state`（`{stopped_at, pending, inflight}`）。`collect_liepin.py` **每关键字轮次前**、`detail_collect.py` **每候选人前**自查 `stop_requested(t0)` → **干净收尾**（已采数据照常写盘；输出 JSON 带 `"stopped": true`）。
- **语义（关键）**：**一次性刹车，不做粘性封锁** —— 停"此刻正在跑的这一波"（`stopped_at > 本次启动时间`），**之后新发起的采集不受影响** → 不需要"恢复"按钮，也不会忘了解除而卡死。
- **B UI**：popup **去掉「暂停/继续」**（对确定性脚本无意义）；「紧急停止」→ **「⛔ 停小猎跑腿」**，使能条件改为**有任务在 executing/pending**；状态行 `⏳ 正在执行：<action>（<source>）` / `⏳ 待执行 N 个` / `空闲`。服务端 `pause/resume` **保留**（控制台那套循环仍用）。
- **自测**：`data/_selftest_tmp/test_stop_switch.py`（**8081 测试桥**，SQLite 用 `AGENT_DB_PATH` 重定向到临时文件，不碰老板的 8080）→ **PASS=11 FAIL=0**，含 ★停之前启动的运行会被拦（True）／★停之后启动的新运行不受影响（False）。
- ⚠️ **生效条件（老板两下）**：① **重启桥**（`server.py` 改了）② **重载扩展**（`edge://extensions` → 小猎跑腿 **v0.2.1**）。

## 7. 关键教训（新对话别重踩）

1. **`.bat` / `.cmd` 一律纯 ASCII**（cmd.exe 按 OEM 代码页解析；`start_bridge.bat` 已因此重写）。
2. **pwsh 工具：PS 5.1（非 PS7）；退出码不可信（一律归一化成 1）；中文输出要显式 UTF-8**。
3. **发岗页 JS：对象字面量不能写在语句位置**（`var x = {}; {…};` → SyntaxError）→ 渲染器改动后跑 `check_html_js.py`。
4. **两个"浏览器助手"别混**：插件是参谋长的眼睛，**小猎跑腿**是小猎的腿。
5. **报告措辞要精确**：把第三方插件写成"DSH 生态已有"→ 直接导致老板误以为基座自带（已更正）。
6. **pip 装了就必须删 `sys.path.insert(源码)`**，否则源码遮蔽 pip 包（`check_env` 已机械化这条例律）。
7. **session id 每次唯一**（同 id 第二次报 `already exists`，跨版本一致）→ 与"不赌会话记忆"一致，零损失。
8. **改动生效三个前提**：改 `server.py` → 重启桥；改扩展 → 重载扩展；改 persona → 跑 `verify_persona_patch.py` 体检。
