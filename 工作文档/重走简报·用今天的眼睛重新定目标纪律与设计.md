| 我们说的 | 真相 |
|---|---|
| *"不赌会话记忆"*（像一条主动的纪律） | 一半是**被 SDK 逼的**（`session "X" already exists`，不能跨进程复用 id） |

## 2. 今天看清的地形（四层落地 + 代价）

**"想让小猎多会一件事"有四条路。越往后越强、越贵、越会作废：**

| | **① 本地代码** | **② 技能 skill** | **③ MCP** | **④ 插件** |
|---|---|---|---|---|
| 模型怎么知道 | 我们口头教（提示词） | **自己翻手册**（目录常驻、正文按需） | 工具清单 | 工具清单 |
| 手从哪来 | 借用 `pwsh`（万能刀） | 借用 `pwsh` | **独立进程** | **运行时内部** |
| 权限边界 | 🔴 软（能绕过） | 🔴 软 | ✅ 硬 | ✅ 硬 |
| 用什么写 | Python / 随便 | **一个 md 文件** | **任何语言** | 🔴 必须 TS/Node |
| 加/改的成本 | 0 | **极低**（放文件即生效，有 watcher） | 中（多一个进程） | 高（装+重启） |
| **会随 SDK 升级作废吗** | ❌ | ❌ | ❌ | 🔴 **会（而且会让车打不着火）** |

**结论（可直接用）**：
- **想省钱** → ① → ②
- **想"硬边界 + 不作废"** → **③ MCP**
- **④ 插件**是**唯一会让整台车起不来**的选项（2026-09-10 那次事故就是这类），**只在"要最紧的集成、且愿意承担升级费"时才上**

**四种形式的"落地"长什么样**（今天都摆过）：
- **本地代码**：一个目录 + 一个可执行入口（`collect_liepin.py` 就是）
- **技能**：`项目根\.agents\skills\<名字>\SKILL.md`（frontmatter 必填 `name`/`description`，可选带 `scripts/`、`references/`、`assets/`）
- **MCP**：一个独立的 server 进程 + 一行注册配置（`mcpServers`）
- **插件**：一个包（`package.json` + 入口代码 + `cordis.patch.yml`）→ 挂到**某个 profile 的** `package.json` → `pnpm install` → **重启那个运行时**

> ⚠️ **注册是"每个运行时各注册一次"，不是一个动作。** GUI（`:3080`，profile `web`）和 SDK 运行时（profile `sdk`）是两台车、两个家。

## 4. 已经花过钱验过的事实（**别重查**）

### 4.1 运行时环境
- 运行时 = **自带的一个 node（24.21.0）+ 冻在里面的 dsh 应用**（229MB 单文件 exe），**不需要系统 node**
- **首跑要解压原生插件**到 `%USERPROFILE%\.cache\pkg`：**第 1 次 initialize ≈ 50 秒，第 2 次 2.4 秒**，解压物 **16 文件 / 19.5MB**（`koffi.node` + `sharp/libvips`）→ **那个位置必须可写**
- 我们的 home：`bestagent\data\dsh_home`（**与 GUI 的 `~/.dsh` 彻底隔离**）；全部调用走 `framework_config.make_harness()`

### 4.2 工具面（实测：**恰好 25 个**）
`create_goal / edit / exit_plan_mode / get_goal / glob / grep / interrupt_agent / job_kill / job_list / job_output / list_agents / pwsh / ralph / read / read_image / send_message / skill / subagent / subagent_fork / todo_write / update_goal / web_fetch / web_search / workflow / write`

- **25 个 schema 合计 26,593 字节 ≈ 6,481 token，每轮都付**
- **最贵的两个**：`pwsh` 4,493 B、`workflow` 4,095 B（占三分之一）
- 🔴 **`web_search` / `web_fetch` 确实挂着** → 它**真能自己上网**，而我们的防线只有 persona 里一句话
- 挂载证据：会话事件 `request/header`（`docs/subsystems/session.zh.md:166-168`）—— **这是"仪表盘"的正规读法**
- 凭据只认环境变量（实测：不加载 `.env` → `MISSING_CREDENTIAL`）

### 4.3 技能（skill）
- DSH 的 skill 子系统 = 四个包：注册表 `dsh-skill` + 本地发现 `dsh-skill-filesystem` + 徽章 + 面向模型的 `dsh-tool-skill`
- 根目录：**项目根（含 `.git` 的最近祖先）** → 我们这边应该是 **`D:\study\bestagent\.agents\skills\`**
- **实测：这个目录不存在**（`data\dsh_home\skills`、`~/.dsh\skills`、`~/.agents\skills` **全都不存在**）→ **所以会话目录是空的，`skill` 工具暂时是瞎的**
- ⚠️ **DSH 没有 `allowed-tools`**（OpenClaw 有）→ **技能在 DSH 里治不了"权限"的病**
- ⚠️ 技能正文**没有大小上限**（官方原文）→ 一个技能可以吃光你下一步的上下文

### 4.4 采集链（今天读代码实测）
- **`execute_spec` 默认 `do_search=True, do_extract=True`**；`collect_liepin.py` 调它时**没关 `do_extract`** → **每个关键字提取了两次，而账本只记一次** → **额度账本被低估一半**
- **城市根本不用修**：配方表里 `city_current` / `city_expected` 都是 **`confirmed`**，`exec_city()` 完整实现了"点其他→搜索城市→重新快照→点过滤结果→确认"并带校验
- 配方表 **29 组**：**25 组 `confirmed`** / **4 组 `pending`**（`industry_current`、`position_current`、`industry_expected`、`resume_lang`）
- 城市那两组的**可见标签是动态的**（页面记忆最近选择）→ **不能硬编码城市名**，要走"其他"读全量
- 城市是**面板多选**（"已选 x/9"）；目前城市"其他"是 `occurrence=1`，期望城市是 `2`
- ⚠️ **"目前城市" ≠ "期望城市"**：**人在哪 vs 想去哪**，是两个维度（本单 南京→目前城市、苏州→期望城市）

### 4.5 桥（小猎跑腿）
- 纯 Python，**不依赖 SDK 版本**（我们的资产）
- 页面判定 / 端点契约 / 服务端授权 / 三字段去重锚点 —— **上一代（智猎助手插件 + Wails httpapi）都有**，现在这一代**没有**
- 上一代的端点清单（10 个）就是"桥的动作契约"的现成范本
